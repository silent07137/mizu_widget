- lint 通过（0 错误）。剩余提醒涉及较新的 target SDK / Gradle 版本、旧系统忽略的组件属性及字符串国际化；未关闭检查。
- Gradle Wrapper JAR 校验与 Gradle 官方 SHA-256 一致，发行包校验已固定。
- Android 16 真机：16 项平台 Instrumentation 测试全部通过，包括手动选择的 15 / 30 FPS。
- 精简主界面、配置页、关于页与图片预览文案，移除装饰标题和重复说明；已在真机进行截图检查。
- 关于页的 GPL v2 全文弹窗正常读取并显示打包的许可正文。
- 系统 SAF 选择本机自制 PNG，持久读取授权成功。
- 棋盘格正确展示 PNG 透明区域，桌面组件不显示棋盘格。
- 系统桌面确认 pin 添加成功，实际 widget ID 保存配置。
- 点击已添加的组件进入配置，正确恢复图片与效果。
- 强制停止应用后重新进入组件配置，持久 URI 仍可读取、预览恢复正常。
- Release 的 R8 压缩、资源收缩、未签名 APK 和 AAB 本地构建通过；没有使用正式签名材料。
- 用户提供的真实 GIF（扩展名为 JPG）：SAF 选择后按内容识别，2 FPS 和手动选择的 30 FPS 预览均在 4 次图像区域采样中出现 4 个不同结果；配置持久保存为 30 FPS。
- 真实 GIF 经桌面 pin 添加成功，原有静态组件配置保留。图片、文件名、URI 和截图只用于本机测试，没有进入仓库。
- 桌面播放期间结束应用后台进程，确认进程不存在，GIF 图像区域 4 次采样仍有 4 个不同结果；重新进入配置正确恢复 30 FPS。关闭播放后静态预览正常。
- 保存关闭播放的配置后，桌面图像区域 4 次采样结果一致；播放开关确实切换到静态显示。
- Android 16 强制停止应用时，系统会暂时禁用该应用的全部组件；重新打开应用后恢复。这与后台进程回收是不同的系统行为，参见 [Android 官方说明](https://developer.android.com/about/versions/15/behavior-changes-all#widgets-disabled)。
